# About

## Description

A fast, polished falling-block puzzle game that runs entirely in the terminal. Built in Rust with Ratatui and Crossterm. Plays with modern rotation, 180° spins, hold, a ghost piece and a seven-piece bag. Includes in-game settings for controls, DAS and ARR. Tracks finesse with an optional retry-on-fault training mode.
