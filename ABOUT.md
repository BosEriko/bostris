# About

## Description

A fast, polished falling-block puzzle game that runs entirely in the terminal. Built in Rust with Ratatui and Crossterm. Plays with modern rotation, 180° spins, hold, a ghost piece and T-spin scoring. Battle an AI opponent across seven difficulty levels. Tracks finesse with an optional retry-on-fault training mode.
